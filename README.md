# Live Transaction Monitor Dashboard

## 📌 Project Description

The Live Transaction Monitor Dashboard is a modern web application that simulates and displays transaction activity in real time. It provides users with an interactive interface to monitor transactions, search through records, and observe dynamic updates.

This project showcases front-end development skills, component-based architecture, and state management using React.

---

##  Features

*  Global search across transactions
*  Dynamic transaction list rendering
*  Responsive and modern UI
*  Reusable component structure


---

##  Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Framework:** React (Vite)
* **State Management:** Context API
* **Styling:** Custom CSS

---

##  Future Improvements

###  Advanced Filter Functionality

To improve usability and provide better data control, the following filtering features will be implemented:

* Filter by **transaction status** (success, pending, failed)
* Filter by **date range** (today, last 7 days, custom range)
* Filter by **amount range**
* Combine multiple filters with search for more precise results

---

### ⏱ Real-Time Transaction Simulation (Polling)

To simulate a live financial system, the application will introduce polling:

* Fetch or generate new transactions every **10 seconds**
* Automatically update the dashboard without refreshing the page
* Highlight newly added transactions for better user visibility and must be on top of the list
